# Agentes

Todas as instruções deste repositório estão num arquivo só: o
**[CLAUDE.md](CLAUDE.md)**. Leia-o inteiro antes de qualquer alteração, seja a
ferramenta qual for. Ele traz os princípios do jogo, o produto, o código, os
testes, os agentes agendados e as decisões do dono.

Não há outro guia. A fila de trabalho é o [ROADMAP.md](ROADMAP.md) e o registro
das execuções é o [DIARIO.md](DIARIO.md); os dois cedem ao `CLAUDE.md`.
